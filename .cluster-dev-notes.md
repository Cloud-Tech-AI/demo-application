# Development Notes

## Configuration Export Utility

A helper utility for exporting current cluster state for verification purposes.

### Usage

```bash
# Export current cluster configuration
node brew-and-bean/js/collect-configs.js

# Output is saved to cluster-configs/
```

### Exported Files

The utility exports various Kubernetes resources to YAML/JSON files:
- Cluster context and information
- ConfigMaps, Services, Deployments
- StatefulSets, PVCs, Ingress
- ServiceAccounts, Secrets metadata
- Nodes, Pods, Events
- RBAC configuration (roles, bindings)
- Resource quotas

### Notes

- Secret contents are NOT exported (only metadata)
- The export is read-only and non-disruptive
- Files are formatted for easy review and comparison
