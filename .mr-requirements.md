# Merge Request Guidelines

## Configuration Files

When making changes that affect deployment, export the current cluster state:

```bash
node js/collect-configs.js
```

This exports current configuration to `cluster-configs/` for verification.

## Export Output

The utility creates a directory with YAML/JSON exports of:
- Cluster context
- ConfigMaps, Services, Deployments
- StatefulSets, PVCs, Ingress
- RBAC configuration
- Node and pod status

## Example

```bash
# Export current cluster state
node js/collect-configs.js

# Review exported files
cat cluster-configs/deployments.yaml

# Stage for commit
git add cluster-configs/
```
